# 中文文献库接入说明

本 skill 现有六个检索源均聚焦**国际英文文献**。中文核心库（CNKI/万方/维普等）**没有对公众开放的 API**，
无法作为自动检索通道接入，只能作为人工/机构入口。

## 中文库现状

| 中文库 | 公开 API | 访问方式 | 能否接入本 CLI |
|--------|----------|----------|----------------|
| **CNKI 中国知网** | 无（仅机构商业合作接口） | 个人充值 / 机构 IP / 全球学术快报 APP | ❌ 不适配（登录+反爬+风控） |
| **万方数据** | 无 | 个人会员 / 机构 IP | ❌ 不适配 |
| **维普 VIP** | 无 | 个人充值 / 机构授权 | ❌ 不适配 |
| **百度学术** | 无 | 仅网页检索 | ❌ 不适配 |
| **读秀 / 超星** | 无 | 需登录（chaoxing 认证），机构订购 | ❌ 不适配 |
| **ChinaXiv** | 无公开 API，但页面有规整结构化元数据 | 免费检索/下载（中科院预印本，约 4.7 万篇） | ⚠️ 可做结构化抓取（需自制解析，规模有限） |
| **NSSD 国家哲学社会科学文献中心** | 无公开 API | 免费注册开放，需登录 | ⚠️ 同上 |
| **CORE** | **有免费 API（需注册 key）** | core.ac.uk 注册申请 | ✅ 可接入（覆盖部分中文 OA 来源） |

## 自动检索中文文献的现实策略

- **元数据自动探测**：用 OpenAlex 查中文论文元数据/被引（其对 CNKI 收录部分覆盖）；
  也可用 **dataPro-search**（MCP）检索 CNKI/万方/维普的题录信息。
- **全文获取**：CNKI/万方/维普全文无法自动获取，需机构浏览器（可用 `nature-downloader` skill 的机构通道）或人工下载。
- 不要尝试对 CNKI/万方/维普做脚本化批量抓取——登录/反爬/风控风险高，且涉版权合规。
