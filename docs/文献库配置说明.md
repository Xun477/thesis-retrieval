# 文献库配置说明

本 skill 允许你**持久化**选择要检索的文献库，首次运行初始化一次，之后每次都直接用你选好的库，无需重复选择。

## 首次运行（初始化）

第一次运行 `thesis_retrieval.py`（未传 `--sources`、也没有保存过配置）时，会：

1. 弹出文献库多选菜单（openalex/crossref/semantic_scholar/pubmed/scopus/wos 共 6 个）。
   - 输入序号或名称多选，如 `2,3` 或 `crossref,pubmed`；`all` 全选；直接回车 = 全部可用的库。
2. 选择结果由程序**自动保存**到 `resources/config/sources.env`，以后每次运行都用这套库（不再单独询问"是否保存为默认"）。

## 之后运行

- **已有保存配置**：直接使用 `resources/config/sources.env` 里的库，不再弹菜单、不再询问。
- **想临时换库（仅本次）**：运行时加 `--sources`，例如：
  ```bash
  python scripts/thesis_retrieval.py "silver nanowire" --sources openalex,wos
  ```
  显式 `--sources` 优先级最高，会覆盖保存的配置，但不改动保存文件。

## 想永久换文献库，改哪里？

有三种方式，任选其一：

| 方式 | 操作 |
|------|------|
| **① 改配置文件（推荐）** | 编辑 `resources/config/sources.env`，改 `SOURCES=` 那一行，如 `SOURCES=openalex,crossref,wos`（逗号分隔）。改完立即生效。 |
| **② 删除配置重新初始化** | 删除 `resources/config/sources.env`，下次运行会重新弹菜单选择并自动保存。 |
| **③ 命令行覆盖 + 保存** | `python scripts/thesis_retrieval.py "query" --sources openalex,wos --save-sources`，把本次选择写回保存文件。 |

> 注意：`resources/config/sources.env` 是**本机用户配置**，不会被 git 提交（已加入 `.gitignore`）。换机器 / 换人使用时需重新初始化。

## 常用命令速查

| 命令 | 作用 |
|------|------|
| `python scripts/thesis_retrieval.py "query"` | 用保存的库检索（首次会初始化） |
| `... --sources openalex,crossref` | 仅本次用这些库 |
| `... --sources ... --save-sources` | 本次选择并保存为默认 |
| `python scripts/thesis_retrieval.py --list-sources` | 查看各库覆盖/凭据/语法 |
| `python scripts/thesis_retrieval.py --check-keys` | 检查 API key |
