# 摘要筛选说明

本 skill 支持**按摘要自动筛选文献**：检索后，AI 会读每篇文献的摘要，判断是否符合你的需求，并标注 `[符合] / [不确定] / [排除]`。

## 首次运行

第一次运行（未设置过偏好）时会询问：

```
是否按摘要自动筛选文献（读摘要判断每篇是否贴合需求）？
  [1] 以后都是（推荐）   [2] 仅本次   [3] 这次不用   [4] 以后都不用
```

| 选项 | 含义 | 效果 |
|------|------|------|
| **1. 以后都是** | 每次检索都自动按摘要筛选 | 保存为默认，不再询问 |
| **2. 仅本次** | 这次筛选，以后不固定 | 下次运行仍会询问 |
| **3. 这次不用** | 本次不筛选 | 下次运行仍会询问 |
| **4. 以后都不用** | 彻底关闭筛选 | 保存为默认，不再询问 |

## 之后想改，改哪里？

三种方式，任选其一：

| 方式 | 操作 |
|------|------|
| **① 改配置文件（推荐）** | 编辑 `resources/config/preferences.env`，改 `FILTER_BY_ABSTRACT=` 那行：`always`（以后都是）/ `once`（仅本次）/ `no`（这次不用）/ `never`（以后都不用）。改完立即生效。 |
| **② 删除配置重新询问** | 删除 `resources/config/preferences.env`，下次运行会重新弹菜单让你选。 |
| **③ 命令行临时覆盖** | `--filter always / once / no / never`，单次生效不改文件。 |

## 摘要的覆盖范围

- **有摘要**：OpenAlex、CrossRef、Semantic Scholar（免费直接返回）。
- **默认无摘要**：Scopus（需 COMPLETE view 多耗配额）、PubMed（需额外 efetch 请求）、WoS（API 本身不提供摘要）。
- **跨源兜底**：同一篇论文（同 DOI）若 OpenAlex/CrossRef 返回了摘要，会自动补到其他源的结果上。

## 常用命令

```bash
# 带摘要文本输出
python scripts/paper_research.py "query" --abstracts

# 导出 JSON（始终含完整摘要字段，供 AI 筛选）
python scripts/paper_research.py "query" --out results.json

# 临时关闭本次筛选
python scripts/paper_research.py "query" --filter no
```
